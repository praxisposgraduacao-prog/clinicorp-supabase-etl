================================================================================
ERROS COMUNS E SOLUÇÕES
================================================================================

Erro: HTTP 400 Bad Request
  Causa: Parametros incorretos (antes: data_inicial/data_final)
  Solucao: Use from/to em vez disso

Erro: HTTP 401 Unauthorized
  Causa: Credenciais incorretas ou token expirado
  Solucao: Verifique .env - usuario API e token

Erro: HTTP 404 Not Found
  Causa: Endpoint nao existe (ex: /patient/list)
  Solucao: Use /patient/get ou outra alternativa

Inconsistencia: businessId vs business_id
  Causa: Pode ser proposital na API
  Solucao: Use businessId para /appointment/list
           Use business_id para /financial/*
